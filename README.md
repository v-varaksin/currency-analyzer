# Анализатор курса валют 📊

End-to-end Python-приложение для автоматизированного сбора, статистического анализа, визуализации и прогнозирования курса японской иены с использованием REST/XML API Центрального Банка РФ.

## 🎯 Возможности приложения
- **Сбор данных:** Автоматизированный помесячный парсинг исторических курсов за 5 лет через API ЦБ РФ (requests + xml.etree.ElementTree).
- **Статистический анализ:** Расчет минимальных, максимальных и средних значений курса по годам с группировкой и очисткой данных через Pandas и NumPy.
- **Визуализация:** Построение интерактивных линейных графиков динамики курса (с выделением точек-аномалий max/min) и столбчатых диаграмм средних значений с помощью Matplotlib.
- **Прогнозирование:** Реализация модели линейной регрессии (NumPy polyfit) для экстраполяции тренда и прогноза курса на 365 дней вперед.
- **Экспорт и облако:** Сохранение исходных данных и аналитических отчетов в Excel (openpyxl) с опциональной автоматической загрузкой файла на Яндекс.Диск через REST API.
- **Графический интерфейс:** Удобное десктопное приложение на Tkinter с интуитивным управлением (7 основных функций).

## 🛠️ Стек технологий
- **Язык:** Python 3.x (объектно-ориентированное и функциональное программирование)
- **Библиотеки анализа и визуализации:** pandas, numpy, matplotlib
- **Работа с сетью и данными:** requests, xml.etree.ElementTree, openpyxl
- **Интерфейс:** tkinter
- **Сторонние API:** Центральный Банк РФ (XML Dynamic API), Яндекс.Диск API
